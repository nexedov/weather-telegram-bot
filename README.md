# Простой погодный телеграм-бот

Асинхронный бот для Телеграма, который показывает текущую погоду и собирает прогноз на ближайшие сутки. 

Писал на python с использованием aiogram 3, с использованием API OpenWeatherMap. Бот не просто выдает цифры, но и подкидывает нормальные человеческие советы, че натянуть на себя перед выходом на улицу (по типу чтобы не продуло и под дождь не попасть).

# Полный функционал:

1. Ищет погоду по названию города (понимает и русский, и английский).
2. Умеет определять геопозицию по кнопке со смартфона и выдавать локальный прогноз.
3. Показывает почасовую погоду на ближайшие 24 часа.
4. Выдает рекомендации по одежде в зависимости от температуры, ветра и осадков.
5. Не забивает чат спамом — интерфейс плавно перерисовывается (изменяется одно активное сообщение) прямо в одном сообщении  на инлайн-кнопках.
6. Защищен от флуда и ddos-навесов (стоит middleware на ограничение частоты кликов), плюс кэширует погоду в память на 10 минут, чтобы не выжирать лимиты запросов к API.

# Как запустить проект у себя:

1. Скачать проект и внутри открыть папку с ним через PyCharm.
2. Внизу во вкладке Terminal вставить команду для установки всех нужных библиотек:
```bash
pip install -r requirements.txt
```

3. Скопировать файл `.env.example` , переименовать в  `.env` .
4. Зарегистрироваться на OpenWeatherMap, взять api'шку. Вставить его вместо подсказок `OPENWEATHER_API_KEY=`  . Аналогично с токеном бота. `@BotFather` -> api в созданный файл `.env` `weather_bot_final.py`
5. Открыть файл weather_bot.py в PyCharm , запустить. Бот запущен, можно тестировать !
